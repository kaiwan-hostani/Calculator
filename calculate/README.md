# Calculator

This is a simple calculator built with HTML, CSS, and JavaScript.

It supports basic calculations such as:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers

It also includes:

- AC button to clear the calculator
- Backspace button
- Error handling for division by zero

## What I Learned

While building this project, I practiced:

- DOM manipulation
- Event handling
- JavaScript conditions
- Working with numbers and strings
- Basic error handling
